# Strategy — gephi-lite-src

## What this is
A local clone/mirror of the upstream open-source project [Gephi Lite](https://github.com/gephi/gephi-lite) — a free web app for visualizing and exploring network graphs, built on React/TypeScript/sigma.js/graphology. This is third-party code (GPLv3), not something Bruno authored or is building as a product.

## Role in the portfolio
Currently dormant. There is no route for it in the live Caddy site (`/home/bruno/apps/caddy/Caddyfile` has no `gephi` handler) and no container for it running on the Mac Mini. It appears to exist as a local working copy for potential graph-visualization use (e.g. exploring relationships between assets/notes) rather than as a deployed tool or a repo Bruno is contributing upstream changes to. It has no dependency relationship with any other repo in this sweep.

## Scoring
Not applicable — this is a vendored/mirrored open-source tool, not a Bruno-owned or scored business asset.
